# The canonical B3 mechanism is di-zinc with a Zn1-bound hydroxide nucleophile

Canonical B3 Zn1 is three histidines plus the bridging hydroxide, four
coordinate; the conserved Asp120 is a **Zn2** ligand; and the substrate is held
across both metals, with the anionic leaving nitrogen stabilised at Zn2.

This is the baseline the thesis is measured against, so it is stated from
deposited structures rather than from reviews: 1SML (L1) His84/86/160 + HOH
1.88 A, 5B15 (SMB-1) His72/74/150 + HOH 1.83 A, 7UHJ (L1 + moxalactam)
His105/107/181 (¶208).
