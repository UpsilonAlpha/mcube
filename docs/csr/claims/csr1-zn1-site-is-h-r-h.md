# CSR-1's Zn1 site is H-R-H, not H-H-H

BBL His116 -> His88, **Arg118 -> Arg90**, His196 -> His164. Arg90 stands where
canonical B3 has its third Zn1 histidine, so the metal has **two** protein
ligands, not three (¶40; user correction twice, standing rule 4).

**This changes what counts as over-coordination.** The canonical-equivalent
four-coordinate sphere here is two His + hydroxide + one water, so a second
solvent ligand is not an excess until it is counted against two protein
ligands (¶41, correcting ¶38). Standing rule 4 exists because that miscount was
made.

Arg90 itself is not a ligand: 6NC5 puts Arg118 NH1 **4.02 A** from the zinc,
and Krco 2023 argues Arg/Lys at metal positions are protonated and poor ligands
(¶22).
