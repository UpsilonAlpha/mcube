# Canonical B3 Zn1 is three histidines plus one water, four-coordinate

Measured from the deposited files (¶208):

| structure | Zn1 site |
| --- | --- |
| 1SML, L1 | His84/86/160 + HOH **1.88** |
| 5B15, SMB-1 | His72/74/150 + HOH **1.83** |
| 7UHJ, L1 + ligand | His105/107/181 + MX0 O1 **2.63** |

Four-coordinate in each. The canonical reference for it is Ullah 1998 on L1
(1SML), cited in ¶40.

**One measured exception inside the subclass**, which matters because it is the
nearest thing to a precedent for a non-histidine at a Zn1 ligand position:
**GOB-18's Zn1 is an HQH site** - Gln98 OE1 at **2.04 A** (5K0W, ¶208,
measuring what ¶124 had read). So a glutamine amide can be a Zn1 ligand in a B3
enzyme.

**That precedent does not transfer to CSR-1, and reading it as though it did is
a mistake this log has made** (¶124). GOB-18's glutamine is BBL **116**, a Zn1
ligand position; CSR-1's Gln93 is BBL **121**, a Zn2 ligand position. Same
residue type, different site.
